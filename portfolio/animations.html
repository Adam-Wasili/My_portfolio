Animated Concepts

This page demonstrates the CSS and JavaScript animations used throughout the portfolio. Each one is subtle and purposeful — guiding attention without getting in the way of reading.

1. Animated Text

A typing effect cycles through professional descriptions: type, pause, delete, then move to the next phrase.

Computer Science Student

The same effect runs in the Home page hero.

2. Hover Effects

Navigation links, buttons and project cards respond to the pointer with a colour change, a lift and a shadow. Hover over each card below to see three different techniques in action.

Card lift

The whole card rises with a shadow on hover.

Image zoom

The image scales up inside a fixed frame on hover.

Link card →

Hover changes the background and the arrow shifts right.

3. Animated Background

Three blurred orbs drift up and down at different speeds, creating slow ambient motion behind the section. All three share one keyframe animation; their individual size, horizontal position, duration and start delay come from CSS custom properties set on each element.

4. Animated Skill Indicators

Each bar starts empty and fills to its percentage when the page loads, using a single keyframe animation whose end width comes from a CSS custom property on the element.
